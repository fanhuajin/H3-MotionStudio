# H3 抖音选片助手

在现有浏览器的抖音页面勾选视频，一次复制全部链接，再由用户手动提交到 H3 的跳舞任务。所有选片均用于跳舞，不提供唱歌/跳舞分类。扩展独立运行，不连接 H3 后端，不下载视频、不启动备料或付费生成。

## 安装（Edge / Chrome）

1. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
2. 开启「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择本 README 所在的 `extensions/douyin-picker` 文件夹（包含 manifest.json）。
4. 刷新已打开的抖音网页。右下角出现「H3 选片」。

本机目录：`D:\project\H3-MotionStudio\extensions\douyin-picker`。
安装方法依据 [Edge 官方文档](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。后续原地更新文件后，在扩展管理页点击重新加载，再刷新抖音页。

## 使用

- 在浏览器「扩展」菜单把「H3 抖音选片助手」固定到工具栏。点击插件图标即可关闭 / 开启，图标角标显示「开 / 关」。页面助手右上角也可直接「关闭」，再从工具栏图标开启。
- 开关对同一浏览器配置内的全部抖音标签页生效，并在刷新和重启后保持；关闭时隐藏清单与卡片勾选框、停止扫描页面，已选清单保留。
- 打开自己的「喜欢」列表，勾选视频卡片左上角的选择框。取消勾选即可移除，不需要设置分类。
- 每排右侧的「选择整排」可一次补选该排全部视频；整排已选时显示「取消整排」，只移除这一排。按当前页面实际排列识别，列数变化和末排不足一排也可使用；右侧空间不足时按钮放在末张卡片内。仅处理页面中已加载且当前可见的卡片。
- 点开视频播放，待切换稳定后，用助手的「选择当前视频」加入，再点可取消。没有明确作品号时按钮禁用，不会把喜欢列表地址当成视频。
- 已选清单可移除、点击标题新开原视频核对，按作品号去重。
- 点击「复制全部链接」，粘贴到 H3 的跳舞链接输入框，然后手动提交。复制受限时会显示已全选的文本，按 Ctrl+C 即可。
- 收起助手可继续看视频；列表勾选仍可使用。清空清单需在助手内再次确认。

## 数据和边界

- 清单使用扩展本地存储，刷新、重启浏览器仍保留；同一浏览器配置中的标签页共享。卸载扩展会删除清单，不同步到其他设备。
- 仅申请 storage 权限，仅在 `https://www.douyin.com/*` 运行。不读取 Cookie，不调用私有接口，不批量抓取整个喜欢列表；只读取页面已经加载的视频链接、标题和缩略图。清单展示缩略图时浏览器会向原图片地址请求图片。
- 卡片选择依赖页面中带图片的 `/video/作品号` 链接；抖音改版、图文卡片或无明确链接的内容可能不显示选择框，可点开视频后从助手选择。播放选择以地址栏的 modal_id 或 /video/ 作品号为准，切换后需等约一秒。
- 标题无法准确读取时显示作品号，不猜测当前视频身份。扩展内按作品号去重；H3 新建和追加时也会把明确带相同作品号的 `/video/` 与 `modal_id` 链接视为同一作品，包括过去已登记的不同写法。不同短链接仍不联网解析合并。
- 不预判视频真实时长，跳舞 40 秒限制继续由 H3 下载后的既有校验执行。
