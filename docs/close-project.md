# 关闭项目

侧栏「系统」区增加「关闭项目」。点击后弹窗确认，说明正在运行的生成、下载和发布会中断，已保存文件和记录保留。取消不调用关闭接口。

确认后停止本项目启动的服务进程树，包括由本项目启动的 ComfyUI、发布执行进程和文件夹选择窗口；不按端口杀进程、不关闭浏览器或外部独立启动的 ComfyUI。已排定的本项目自动关机取消，关闭期间禁止重新排定电脑关机。不会关闭电脑。

后端通过独立延迟退出进程先返回 HTTP 确认，再检查启动进程的路径和创建时间；PID 被复用或无法确认属于本项目时拒绝关闭。只允许本机工作台请求。退出辅助程序的诊断日志保存在 `data/project-close.log`。

页面收到确认后卸载原工作区，等待服务断开；服务持续响应时显示未完成并允许返回重试。断开后显示「启动工作台」，调用与桌面「H3影动高清工作台」相同的启动器。浏览器可能提示确认打开本机程序；启动期间按钮禁用，检测到服务就绪后显示「返回工作台」，两分钟仍未连接则允许重试，并提示使用桌面快捷方式。

`scripts/launch-workbench.vbs` 每次启动时为当前 Windows 用户注册 `h3-motionstudio://` 启动入口，关闭全部项目进程后仍可使用，无需常驻服务或管理员权限。注册命令只运行固定启动器，不接收 URL 参数。可用 `cscript //nologo scripts/launch-workbench.vbs --register-only` 单独注册，不启动项目。

检查使用进程桩，不调用真实关闭接口。代码更新需用户自行重启后端一次后生效。
