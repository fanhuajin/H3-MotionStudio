# 关闭项目

侧栏「系统」区增加「关闭项目」。点击后弹窗确认，说明正在运行的生成、下载和发布会中断，已保存文件和记录保留。取消不调用关闭接口。

确认后停止本项目启动的服务进程树，包括由本项目启动的 ComfyUI、发布执行进程和文件夹选择窗口；不按端口杀进程、不关闭浏览器或外部独立启动的 ComfyUI。已排定的本项目自动关机取消，关闭期间禁止重新排定电脑关机。不会关闭电脑。

后端通过独立延迟退出进程先返回 HTTP 确认，再检查启动进程的路径和创建时间；PID 被复用或无法确认属于本项目时拒绝关闭。只允许本机工作台请求。退出辅助程序的诊断日志保存在 `data/project-close.log`。

页面收到确认后卸载原工作区，等待服务断开；服务持续响应时显示未完成并允许返回重试。浏览器页面可自行关闭，下次双击原启动入口重新启动工作台。

检查使用进程桩，不调用真实关闭接口。代码更新需用户自行重启后端一次后生效。
