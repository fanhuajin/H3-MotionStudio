# 三端批量发布

入口 `/publish`，侧栏「三端批量发布」。使用本项目的任务列表、灰绿操作按钮和原生弹窗，队列状态保存在 `data/publisher/queue.json`。切换路由或刷新不停止发布。

## 使用

1. 添加作品：点击后打开原来的 Windows 文件夹选择框，在作品父目录中按 Ctrl / Shift 多选作品文件夹，确认后直接加入队列；取消不添加。入口「其他添加方式」保留读取目录、手动粘贴路径和导入旧队列。目录扫描最多向下两层，不修改文件。添加重复目录会跳过。系统选择框由独立进程运行，不在后端工作线程中初始化窗口或 COM；同一时间只允许一个选择框。
2. 安排时间：表格中分别编辑日期和小时，日期离开输入框时保存，小时选中即保存；每次只保存改动字段，显示保存中和失败反馈。勾选多条后通过工具栏「安排时间」只选择日期，保存时将所选作品设为定时发布，每条原有小时保持不变，不重新排时；没有有效改动时不能保存。默认明天 01 时开始，后续新增作品逐条顺延一小时。页面不提供立即发布切换入口，历史立即发布记录不会自动修改，批量保存日期时仅将所选记录改为定时发布。时间为北京时间，分钟由平台页面保留；实际时间单独记录。
3. 发布平台：每端可选择待发布或不发布；已完成、发布中不可直接重置。待核对需先到平台核实，再点击状态确认已成功或未发布。
4. 查看视频：打开和切换视频时自动带声音播放，浏览器阻止自动播放时显示「点击播放」，关闭或切换时停止旧视频。抖音、B站、小红书勾选位于播放器右上方，鼠标悬停或键盘聚焦播放器区域时显示，触屏设备常显。新作品默认三端均选中，取消勾选即时保存为「不发布」，实际执行会跳过该端；重新打开和切换不会重置已保存选择。已完成、发布中和待核对状态不能直接勾改。使用键盘 ↑ / ↓ 切换前后视频，平台复选框等输入控件保留自身键盘行为；Esc 和关闭按钮正常关闭。不显示封面、文案和手动完成操作。浏览器不支持的原视频复用项目已有 H.264 预览缓存，原视频不覆盖。
5. 页面直接展示完整作品列表，不提供状态筛选标签和单平台运行按钮。「开始 / 继续发布」与「添加作品」在同一操作栏，暂停、继续和停止也在此栏操作；发布按抖音、小红书、B站顺序执行。点击开始后先核对浏览器已有标签页，补开缺少的抖音、小红书、B站作品管理页，确认三个页面已加载后才进入发布。已有该平台的投稿编辑页复用，不覆盖未完成稿件；无法核对已有页面时停止，不盲目新开。运行前弹窗说明真实发布范围，已完成与不发布状态跳过。各平台的状态、开关及底层执行能力保留。
6. 运行时不要操作鼠标键盘。Esc 或网页暂停按钮暂停，继续恢复当前操作；停止会在执行检查点退出，未确认的提交保留待核对。删除记录需确认，仅删除记录，作品文件保留。

## 素材与恢复

沿用原引擎的精确素材和平台校验：`发布文案.txt`、`最终成片.mp4`（或目录唯一视频）、`B站4x3.png`、`抖音3x4.png`。B站分类由作品目录中的 `_跳舞` / `_唱歌` 确定。各端的文案长度、声明、保存权限、日历及小时滚动核验规则沿用原项目，开始所选平台前统一预检。

添加弹窗内「导入原三端队列」读取指定 `multi_publish_state.json`，保留平台状态、提交标记和历史检查点；不修改原文件。重复目录保留当前记录，不用旧状态覆盖。原发布中记录按提交标记恢复为失败或待核对，已完成不会重发。队列文件损坏时停止写入，避免覆盖已有记录。

## 执行环境

执行引擎在 `backend/creator_publish/`，无需原项目目录。桌面输入使用原 Windows MCP 0.8.5、UIA 只读定位、系统鼠标键盘事件和 F6 输入助手。无网页脚本注入或浏览器调试连接。新网页的队列与原项目独立；执行进程共用原三端窗口的 Windows 互斥锁，防止并行操纵桌面。

推荐使用隔离环境，避免改变视频后端依赖：

```powershell
.venv\Scripts\python.exe -m venv data\publisher\runtime
data\publisher\runtime\Scripts\python.exe -m pip install -r backend\requirements-publish.txt
```

后端优先使用该环境，无此环境时使用后端 Python。输入助手只在实际执行时启动，结束时释放快捷键。工作进程异常退出后，后端将发布中记录按提交标记恢复；后端进程退出时执行进程在下一个检查点停止。诊断输出在 `data/publisher/worker.log`。

三端发布与剪映字幕识别共用跨进程桌面闸门：已有流程占用时，另一流程明确停止并提示稍后重试，不相互抢鼠标。发布运行、暂停或正在安全停止时，批量制作自动关机继续等待。此闸门与视频/GPU 队列无关。

本机迁移时已安装隔离环境。后端由用户自行重启后加载新接口；本次开发不进行真实上传、发布或定时提交。实际平台页面适配仍需使用真实作品验收。

## 离线检查

```powershell
.venv\Scripts\python.exe -B -m unittest tests.test_publish_service
$env:PYTHONPATH = (Resolve-Path backend\creator_publish).Path
.venv\Scripts\python.exe -B -m unittest discover -s backend\creator_publish\tests
npm run typecheck
npm run build
npm run test:sites
```

引擎测试从原项目迁入，桌面和网页操作均由离线桩替换；接口测试使用临时队列与模拟工作进程，不读取实际历史队列。
