# 等待区素材暂存

2026-10-24：未安排出片的任务不再提前创建发布目录。人物图、抽帧和发布文案保存在 `data/batches/{batch}/{item}/publish-materials/`，路径登记为 `prepOutputs`；`prepReady` 识别这些素材，同时兼容既有发布目录。

点击「已安排出片」后，只为所选条目设置 `renderQueued` 并把素材写入正式发布目录，之后沿用现有出片、封面、交付流程。等待区重新开始时的图片检查、未出片任务的失败入口也不创建发布目录。换图或修改文案时根据是否已安排出片更新暂存或正式素材。

已有目录和历史作品不回溯搬动、删除或改名；仍在等待区的旧作品更新素材时先写暂存。内部暂存属于运行素材，保留供恢复与备料检查使用。后端需用户自行重启生效。
