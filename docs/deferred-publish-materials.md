# 等待区素材暂存

2026-10-24：未安排出片的任务不再提前创建发布目录。人物图、抽帧和发布文案保存在 `data/batches/{batch}/{item}/publish-materials/`，路径登记为 `prepOutputs`；`prepReady` 识别这些素材，同时兼容既有发布目录。

点击「已安排出片」后，只为所选条目设置 `renderQueued` 并启动队列，不等待整批素材复制；视频 runner 轮到当前条目后，再把该条素材写入正式发布目录，之后沿用现有出片、封面、交付流程。等待区重新开始时的图片检查、未出片任务的失败入口也不创建发布目录。换图或修改文案时根据是否已安排出片更新暂存或正式素材。

出片编号 `renderIndex` 同样在安排时分配：唱歌、跳舞分别从 001 起，分次安排继续递增；备料失败、等待或删除的未出片条目不占号。页面出片序号、执行顺序和新目录前缀共用此编号。原备料 `kindIndex` 保留。按用户选择，已经进入出片区或已有目录的历史编号不回溯压缩，后续接既有最大号；批次保存 `renderCounters`，已分配的出片号不因删除记录而回收。

已有目录和历史作品不回溯搬动、删除或改名；仍在等待区的旧作品更新素材时先写暂存。内部暂存属于运行素材，保留供恢复与备料检查使用。后端需用户自行重启生效。
