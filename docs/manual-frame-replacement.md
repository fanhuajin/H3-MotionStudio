# 手动更换抽帧

图片封面页的人物图步骤，在「图一」右下角提供「更换抽帧」。每次从本条原视频全时段采样 24 个时间点，排除当前及历史已选画面的近似帧，保留至多 12 个清楚候选，通过现有视觉接口选择实际服装覆盖更完整的一张。该视觉调用可能消耗文本/视觉接口额度，不调用图片生成接口。

没有可用候选、无法确认服装覆盖、视觉接口失败或整脸定位失败时保留原图并提示。原整脸高斯糊法及其范围、强度不变。选帧完成后备份旧图到作品目录的 `.h3-frame-history/`，更新发布抽帧和仍存在的内部抽帧引用；成功前不覆盖，文件或状态保存失败时恢复原图。

只更换参考抽帧，不重做人物图、封面或视频；采用新参考需要用户再点击生成人物图。图片任务与本条备料/出片运行时禁止更换，源视频记录丢失或本地文件不存在时明确提示，不自动下载或启动任务。历史已付费任务的冻结输入不改。候选来自原视频，不能保证一定存在更合适画面，也不能保证视觉判断绝对准确。
