# 发布文案限制

源标题或简介涉及原作者私人经历、自我感慨、纪念或送给自己的表达时，视为没有可用的标题句或简介，直接舍弃，不做同义改写，也不泛化成「送给所有人」。例如「这个饭送给看团播一年多的自己」整句放弃，不保留「看团播一年多」这个私人背景；只提取与视频有关且有依据的信息，结合实际内容、音乐、舞蹈或看点另拟标题和简介。信息不足时使用简短、中性的文案，不编造经历或故事。此规则同样适用于原文仅作参考时的主题与事实提取，通过共享的 `COPY_SOURCE_FIRST_RULE` 应用于预审与按图生成文案，不批量重写已有文案。

上述舍弃范围包括与原作者本人强绑定的强烈情感、身份和人际关系表达，如「这一年只有自己懂」「跳给我男朋友看」，不能通过换人称继续保留。删除文案中明确自述的本人、小号、主页或其他作品引流及相关标签；仅凭 @昵称不能确认账号归属，不猜测账号关联。判断依据是是否依赖原作者的私人背景，不按「我」或情绪词机械过滤；与视频本身有关的普通情绪，如「这段旋律好治愈」「这支舞的快乐藏不住」，可以保留。

预审与最终人物图文案共用一套生成规则：先筛除不可用内容，原标题和简介仅作主题与事实参考，结合我们最终人物图、已确认的歌曲或舞蹈及作品看点重新创作，不能直接沿用原句，也不能只换词、调语序或标点；可保留准确的歌名、舞种等必要事实，不编造内容。模型不可用时使用中性兜底，不复制或引用源描述。标题去掉话题与 emoji，20 字以内；简介一到两句、自然表达作品看点或普通情绪，不强求第一人称；标签去重、过滤无关内容后优先沿用，不足时补齐 5 个。两处提示词不另行叠加相反要求。规则修改只影响后续生成，不代表历史文案已批量清理或账号关系已核验。

2026-10-24：用户反馈「都说萝莉有三好」被拒绝，要求限制类似标题。

依据 OpenAI 当前生效的[使用政策（2025-10-29 版）](https://openai.com/policies/usage-policies/revisions/2025-10-29/)，不得性化未满 18 岁者。官网当前首页另有 2026-11-20 才生效的更新，不能当作已生效版本。官方没有发布标题关键词黑名单，也不能据此推断中转站某次拒绝的精确原因。

本项目对发布标题、简介、标签采用更保守的限制：不使用萝莉、正太、幼齿等人设词，不使用未成年人或幼态与性感、诱惑、擦边等组合表达。保留正常甜美、可爱、童年和校园主题，不通过谐音或声明成年保留原有性暗示。

`batch_ai.COPY_SOURCE_FIRST_RULE` 用于预审与按图生成文案；`has_disallowed_copy` 经 `ensure_copy_fields` 覆盖模型输出、源标签、降级和简介兜底。原作品文案含限制内容时采用健康的音乐或舞蹈主题文案。已有读取路径也会校正文案字段。

封面提示词读取的旧发布文案若仍含限制内容，会明确报错，要求先修改发布文案，不提交新封面请求。不批量修改历史文件或重做已有图片；已付费任务的冻结输入仍按原恢复逻辑处理。文字过滤不替代对图片、视频和语义上下文的完整审核，也不能保证渠道一定接受。
