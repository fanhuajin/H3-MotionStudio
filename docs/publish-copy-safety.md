# 发布文案限制

源标题或简介涉及原作者私人经历、自我感慨、纪念或送给自己的表达时，视为没有可用的标题句或简介，直接舍弃，不做同义改写，也不泛化成「送给所有人」。例如「这个饭送给看团播一年多的自己」整句放弃，不保留「看团播一年多」这个私人背景；只提取与视频有关且有依据的信息，结合实际内容、音乐、舞蹈或看点另拟标题和简介。信息不足时使用简短、中性的文案，不编造经历或故事。此规则优先于沿用原文及保留关键词、语气的要求，通过共享的 `COPY_SOURCE_FIRST_RULE` 应用于预审与按图生成文案，不批量重写已有文案。

2026-10-24：用户反馈「都说萝莉有三好」被拒绝，要求限制类似标题。

依据 OpenAI 当前生效的[使用政策（2025-10-29 版）](https://openai.com/policies/usage-policies/revisions/2025-10-29/)，不得性化未满 18 岁者。官网当前首页另有 2026-11-20 才生效的更新，不能当作已生效版本。官方没有发布标题关键词黑名单，也不能据此推断中转站某次拒绝的精确原因。

本项目对发布标题、简介、标签采用更保守的限制：不使用萝莉、正太、幼齿等人设词，不使用未成年人或幼态与性感、诱惑、擦边等组合表达。保留正常甜美、可爱、童年和校园主题，不通过谐音或声明成年保留原有性暗示。

`batch_ai.COPY_SOURCE_FIRST_RULE` 用于预审与按图生成文案；`has_disallowed_copy` 经 `ensure_copy_fields` 覆盖模型输出、源标签、降级和简介兜底。原作品文案含限制内容时采用健康的音乐或舞蹈主题文案。已有读取路径也会校正文案字段。

封面提示词读取的旧发布文案若仍含限制内容，会明确报错，要求先修改发布文案，不提交新封面请求。不批量修改历史文件或重做已有图片；已付费任务的冻结输入仍按原恢复逻辑处理。文字过滤不替代对图片、视频和语义上下文的完整审核，也不能保证渠道一定接受。
