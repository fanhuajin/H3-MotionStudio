# 工作区内容展示约定

内容展示集中在 `src/workspace-content.css`，由 `src/main.tsx` 在基础主题后引入。作用范围是工作区内容和业务弹窗，不改变登录页、侧栏、接口、任务状态或生成规则。

## 参考与取舍

- [shadcn/ui 官方布局](https://ui.shadcn.com/blocks?category=dashboard)：参考内容分区、卡片层次与克制的工具栏。
- [shadcn-admin 社区项目](https://github.com/satnaing/shadcn-admin)：参考 React/Vite 后台的表单、任务列表与响应式组织方式。
- [Carbon 官方表格规范](https://carbondesignsystem.com/components/data-table/usage/)：参考工具栏集中操作、行内状态与按需展开详情。

使用本地 CSS 实现，不引入组件库、远程字体或第三方组件源码。保留现有深色灰绿配色；不使用宣传首页式大标题、装饰统计卡或额外动画。

## 页面展示

| 页面 | 展示方式 |
| --- | --- |
| 批量制作、批量发布 | 表格为主，工具栏与行内操作对齐，详情继续按需展开 |
| 歌曲生成、动作迁移 | 设置与执行采用独立卡片，宽屏双栏、窄屏顺序排列 |
| 二采放大、音色转换、生成字幕 | 沿用文件多选表格，设置与处理结果分区展示 |
| 图片与封面 | 作品列表、图片预览、操作区保持清楚的层次，不改变图片比例或裁切 |
| 抖音下载 | 保留单次下载工具，只展示输入与本次视频结果 |

控件、边框、字号、空状态和加载提示采用统一层次。主操作与次操作保持区分；批量工具栏按钮和 Tab 继续使用 34px 高度。执行流程保留现有状态语义；结果视频优先占完整内容宽度，元数据和下载操作放在下方。

工作区双栏在视口不大于 1350px 时转为单栏；图片列表在不大于 760px 时移到预览上方并限制列表高度。表格保留容器内横向滚动，避免挤压整页。

## 验证边界

本次只读检查覆盖九个页面的桌面与窄屏展示、宽屏制作双栏、已有图片和成片区域，未提交生成、发布、文件处理或下载任务。文件队列 API 在运行中的旧后端仍返回 404，需要用户自行重启此前的后端改动；本次展示调整不修改该接口。
