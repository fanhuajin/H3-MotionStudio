# 人物图的糊脸前造型识别

参考视频模式在生成新人物图前，使用现有视觉接口读取未糊脸抽帧的发型、发色、眼镜和可见配饰。只记录可辨认的信息，不提取面部身份。生图接口仍只接收原有的糊脸抽帧和固定身份图，整脸模糊范围与强度不变。

识别结果作为结构化观察记录加入人物图提示词，身份约束仍保留在末尾。明确区分透明眼镜和墨镜，不为露出五官删除眼镜。用户明确提出的造型修改优先。歌曲重设计模式不强制沿用源视频造型。

批量备料、图片工作台自动生图、复制人物图提示词和下载人物图素材包共用记录。复制或下载时，缺少记录会进行一次识别；相同内容的抽帧跨目录复用 `data/source-appearance/` 下的内容缓存，不因改名、换比例、重启或重新生成而重复识别。替换抽帧内容后使用新记录。

每张新内容的抽帧通常新增一次视觉识别费用，不新增生图次数。请求前持久化状态；失败、取消、超时或返回格式异常均不自动重复请求，也不猜测被遮挡的装饰。批量日志或图片工作台收尾说明会提示识别未完成。已有图片不回溯重做。

新人物图请求在工作目录保存 `*.source-prompt.json`，出现 pending 或渠道任务检查点时沿用这份提示词。旧任务没有新快照时不追加新识别描述；批量条目优先沿用其保存的原提示词。渠道层原有输入指纹检查仍生效，输入不匹配时停止，绝不自动重新提交。

验证使用模拟视觉响应和临时缓存，覆盖原始图输入、缓存复用与失效、并发去重、失败与取消、提示词冻结，以及工作台先识别后糊脸再生图的调用顺序。实际装饰还原质量需使用真实作品出图确认。
