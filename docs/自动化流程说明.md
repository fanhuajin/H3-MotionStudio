## 二、逐环节固化要点

### ① 下载
- 走独立下载器 `D:\project\douyin-downloader` 的 REST 服务（按需启动，空闲 60s 自停）
- 本地已有同作品直接复用，不重复下载
- 清单：`D:\EV\download_manifest.jsonl`；媒体：`E:\AI_Exports\Douyin`

### ② 备料
| 产物 | 路径 |
|---|---|
| 6 帧联系表 | `data/batches/{batch}/{item}/source-contact-sheet.jpg` |
| **取景帧（图一）** | `data/batches/{batch}/{item}/scene-frame.jpg` |
| 项目提示词 | `data/batches/{batch}/{item}/出图提示词.txt`（**不用于出图**）|

### ③ 自动生成候选人物图

**输入**
| 项 | 值 |
|---|---|
| **图一** | 该条 `scene-frame.jpg`（源视频取景帧，提供造型/场景）|
| **图二** | `E:\AI_Assets\PortraitIdentity\本人固定参考.png`（唯一身份基准）|
| **提示词** | 唱歌 → `C:\Users\admin\Desktop\4比3图片.txt`<br>跳舞 → `C:\Users\admin\Desktop\9比16图片.txt` |

**执行方式（静默）**
- 独立 ChatGPT 实例：专用 profile `%USERPROFILE%\.codex-automation\profile` + CDP 端口 **9444**
- 登录态来自 `~/.codex/auth.json`，**专用 profile 自动已登录**，无需重新扫码
- **不抢前台、不动鼠标键盘**，窗口可最小化

**取图**
- 生成图在 DOM 里是 `<img src="blob:app://-/...">`
- `fetch(blob:)` 被 CSP 拦 → 用 **canvas 绘制后 toDataURL**
- 落盘：`E:\AI_Exports\H3-MotionStudio\ChatGPT生成图\`
- 上传：`POST /api/batches/{batch}/items/{item}/image`

**同一条作品备过料则直接复用**（不重复下载/抽帧/调模型）

### ④ 审核点
- 页面可看：候选图、标题、简介、标签、本条全部信息
- 页面可改：**画布比例 / 去除字幕 / 迁移模式 / 换候选图**
- 不点确认不出片

### ⑤ 出片（ComfyUI 单链路）
| 类型 | 接口 | 参数 |
|---|---|---|
| 唱歌 | `POST /api/jobs` | 按条目比例、RVC 开、二采开 |
| 跳舞 | `POST /api/jobs/migrate` | 按条目比例、动作迁移/人物替换、按需去字幕 |

### ⑥ 封面（**同一个对话内串行**）
- 素材：`人物图.png` + `发布文案.txt`
- 顺序**写死**：B站 4:3 → 抖音 3:4
- **第一条开新对话并贴人物图；第二条在同一对话里直接发不同指令**（不新开、不重贴）
- 产物：`封面_B站4x3.png`（1448×1086）、`封面_抖音3x4.png`（1086×1448）

### ⑦ 交付
`发布成品\{编号}_{标题}_{作品号}\` 内：
- `最终成片.mp4`
- `人物图.png`（用户/自动生成的那张）
- `发布文案.txt`
- 两张封面

## 三、踩坑清单（改这条链路前必读）

### CDP / ChatGPT 桌面端

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **真实 profile 不开放 CDP** | 用真实登录 profile 启动，调试端口永远不开 | 用**专用 profile**（自动登录） |
| **端口 9222 被主实例占用** | 端口永远开不起来，日志报「CDP 端口 9222 在 60 秒内未就绪」| `H3_CHATGPT_CDP_PORT` **必须是 9444**（我一开始把它设成 9222，出图全部失败）|
| **DPI 缩放** | 125% 下 `GetWindowRect` 返回虚拟化坐标，与截图/点击整体错位 | 进程启动时先 `SetProcessDpiAwareness(2)` |
| **窗口被压住** | `GetWindowRect` 正确但看不到 | 需要时设 `HWND_TOPMOST`；截图用 `PrintWindow`（不受遮挡） |
| **窗口错乱** | 出现 `detached-window`/`avatar-overlay` 等页面，CDP 驱动的不是可见窗口 | 页面选择要求 `index.html` 且排除 detached/avatar |
| **生成图不落盘** | 监听 `generated_images/` 永远等不到 | 图是 blob，必须 canvas 取回 |
| **取回的是参考图** | 拿到的其实是图二本人 | 基线要**贴完图之后**再记；再逐张校验「是否与参考图一致」 |
| **取回的是旧生成图** | sha 与上一次完全相同 | 新对话后**必须校验页面为 0 张图**，否则重试 |
| **长提示词发不出** | 内容留在输入框 | 提示词 2000+ 字会把输入框撑到 1700px 高、**顶部跑到视口外**；聚焦要**点靠近底部**，不能点中心 |
| **发送静默失败** | 没报错但没发出去 | 发送后**校验输入框已清空**，否则重点发送按钮 |
| **附件堆叠** | 输入框里堆了 3 张图 | 每次生成前**清空输入框（含附件）**；移除按钮是 `pointer-events-none`，只能用 JS 触发 |
| **页面「滑来滑去」** | 用户看得到滚动 | 用 JS 操作 DOM，别用 Playwright 的 `click()`（它会自动滚动到可视区） |

### 抖音下载

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **下载器版本旧** | `HTTP 403 Blocked by ArgusSecurityPlugin` | 更新下载器到最新（`git fetch && git merge origin/main`）；H3 的 `server/*` 改动会保留 |
| **会话被风控标记** | 同样的 403，时好时坏 | 去 `/douyin` 刷新登录（`POST /api/douyin/login/start`）|
| **Web 详情接口被 Argus 门禁** | 补 uifid 后变成 `Signature Not Found`（还要页面 SDK 的 `x-secsdk-web-signature`）| **直连兜底**（见下）|

#### 直连兜底（`backend/douyin_direct.py`，2026-09-15 实测通过）

下载器取作品详情用的是 `/aweme/v1/web/aweme/detail/`，现在被抖音 Argus 门禁：
只带 cookie → `Uifid Not Found`；补 uifid → `Signature Not Found`（还需要页面 SDK 签名）。
下载器那边的「页面签名通道」`core/page_bridge.py` 是**桌面版专有**的，开源版没有，所以会时好时坏。

兜底三步（**完全不需要签名**）：

```
① iPhone UA 拉分享页 https://www.iesdouyin.com/share/video/{aweme_id}/
     → HTML 里取出 "uri":"v0300fg10000..."（video_id）+ desc + hashtag_name
② https://aweme.snssdk.com/aweme/v1/play/?video_id={uri}&ratio=1080p&line=0
     → 302 到 CDN 直链
③ 带 referer 下载
```

**要点**：
- `aweme.snssdk.com` 是 App 端旧域名，`/aweme/v1/play/` 是给播放器喂流的直链接口，
  不承担反爬职责，只校验 `video_id` 合法性与时间戳。
- **分享页必须用 iPhone UA**：桌面 Chrome UA 只会拿到配置页（没有视频数据）。
- 它同时给出 **desc 与话题标签**，正好是批量流程备料要用的。
- 接入方式：`batch_worker._download()` 先走下载器 REST，失败时自动兜底，**不改下载器**
  （改它会被下次更新覆盖）。
- 来源：`cat-xierluo/legal-skills` 的 `douyin-nocookie-approach.md`（含 2026-08-30 补记）。

## 五、运行与运维

### 启动（**推荐用 .bat**）
```
双击 D:\project\H3-MotionStudio\启动H3影动高清工作台.bat
```
> ⚠️ 用 `Start-Process` 从临时会话启动的后端**可能随会话结束被杀**，长任务会被中途打断。
> 生产使用请用上面的 `.bat`。

### 关键模块
| 文件 | 作用 |
|---|---|
| `backend/batch_worker.py` | 批次 runner：下载/备料/出片/交付 |
| `backend/chatgpt_image.py` | 图片流程编排（提示词选择、上传、封面）|
| `backend/chatgpt_cdp.py` | **静默驱动 ChatGPT 桌面端**（CDP + canvas 取图）|
| `backend/chatgpt_desktop.py` | 坐标点击版（备用）|
| `backend/app.py` | 批量 API（含 `regen-image`）|
| `src/BatchRoute.tsx` | 批量制作页面 |

### 单链路保证
- 视频/ComfyUI：`pipeline_lock`
- **所有图片操作（人物图 + 封面）：`_IMAGE_LOCK`**，严格一条一条，绝不并发
