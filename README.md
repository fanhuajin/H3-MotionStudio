# H3 MotionStudio

H3 影动高清工作台：把本地 ComfyUI 唱歌生成、RealESRGAN 高清增强、“我的音色”转换和抖音作品下载整合为一个桌面式网页。

## 页面路由

- `/`：影动生成工作台。
- `/douyin`：抖音链接下载、任务状态和已完成视频预览。

两个路由共享同一套深色桌面壳与导航，但各自保留独立的任务内容。

## 首期范围

首期只整合现有的唱歌视频流程：

1. 上传一张人物参考图片和一个带歌声的视频（最长 40 秒）。
2. 填写人物动作要求和运镜要求。
3. 调用“单图唱歌、自动拼接、4:3 运镜版”工作流生成原版成片。
4. 自动调用 RealESRGAN 4x 工作流，输出 1440 x 1080 高清加强成片。
5. 完全关闭 ComfyUI，释放内存和显存。
6. 启动便携音色转换器，分离人声与伴奏并转换成“我的音色”。
7. 用转换后的音频替换高清成片音频，输出最终 MP4。

模型、采样、拼接、锐化和编码参数沿用现有 ComfyUI 工作流，网页不开放这些参数。

## 交互目标

- 与 ComfyUI 同步显示当前执行节点和采样进度。
- 区分已完成、正在执行、等待、跳过和报错节点。
- 显示具体报错节点、简要原因和完整错误详情。
- 页面刷新后恢复任务状态。
- 页面显示 9 个关键阶段、当前 ComfyUI 节点、采样进度和阶段耗时。
- 最终结果直接在页面播放，可下载最终成片、查看原版或重试音色转换。
- 整条流程严格单链路运行：ComfyUI 与便携音色转换器不会同时运行。

## 本地环境

- 项目目录：`D:\project\H3-MotionStudio`
- ComfyUI 目录：`D:\Comfyui`
- ComfyUI 默认地址：`http://127.0.0.1:8188`
- H3 MotionStudio 默认地址：`http://127.0.0.1:8111`
- 抖音下载器目录：`D:\project\douyin-downloader`
- 抖音下载服务默认地址：`http://127.0.0.1:9000`

抖音下载服务会在首次提交任务时自动连接或启动。抖音出现风控时，需要在下载器中配置有效的本机登录 Cookie；页面只显示是否已配置，不会展示 Cookie 内容。

## 启动

双击项目根目录的 `启动H3影动高清工作台.bat`。首次启动会自动安装网页和后端依赖、构建页面并打开浏览器。

后续可以在相同任务框架中增加跳舞等人物视频模式。
